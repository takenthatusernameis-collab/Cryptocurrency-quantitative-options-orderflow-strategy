## LOADER GOTCHAS
- Pass explicit paths to loaders; `load_snapshot_signals(symbol, data_raw)` first arg is the symbol (`"BTC"`/`"ETH"`), second is the options dir.
- Options discovery is non-recursive; `data/raw/options_candles/` holds 101 flat BTC JSON snapshots. `load_snapshot_signals` and the sealed EVAL-42 `run_eval42` hard-code `"BTC"` — EVAL-47's ETH wrapper must pass `"ETH"` + the ETH options dir (do not edit the sealed eval42 script).

Always pass `bars["bar_ends_dt"]`.
- **`load_real_orderflow(symbol, orderflow_path=...)` returns a Pydantic `OrderflowSnapshot`** (fields: symbol, venue, trades, liquidations, funding_rates, timestamp), not a dict — slice via `snapshot.model_copy(update={"trades": trades[-N:]})`.
- `align_options_signal_to_bars(signals, bar_ends_dt)` only reads `snapshot_timestamp` + `options_signal_raw`; component series need a thin wrapper exposing the component under `options_signal_raw` (see `eval42.component_signals`).
- `fetch_okx_history_trades` pages **backward** from `after_cursor` (an OKX trade id); it overshoots the target span by up to one page, so trim to the exact declared start after acquisition.
- `src/data/options_candle_backfill.py` fetches real OKX `history-candles` per option instrument (bar end timestamp, no lookahead). `fetch_live_option_instruments(underlying, *, session, ...)` requires the `session` kwarg; `fetch_option_candles(instruments, *, session, bar, limit, after, before, max_pages)` takes instrument dicts and supports `after`/`before` paging to a historical window.
