Always pass `bars["bar_ends_dt"]`.
- **`load_real_orderflow(symbol, orderflow_path=...)` returns a Pydantic `OrderflowSnapshot`** (fields: symbol, venue, trades, liquidations, funding_rates, timestamp), not a dict — slice via `snapshot.model_copy(update={"trades": trades[-N:]})`.
- `align_options_signal_to_bars(signals, bar_ends_dt)` only reads `snapshot_timestamp` + `options_signal_raw`; component series need a thin wrapper exposing the component under `options_signal_raw` (see `eval42.component_signals`).
- `fetch_okx_history_trades` pages **backward** from `after_cursor` (an OKX trade id); it overshoots the target span by up to one page, so trim to the exact declared start after acquisition.
- `src/data/options_candle_backfill.py` fetches real OKX `history-candles` per option instrument (bar end timestamp, no lookahead). `fetch_live_option_instruments(underlying, *, session, ...)` requires the `session` kwarg; `fetch_option_candles(instruments, *, session, bar, limit, after, before, max_pages)` takes instrument dicts and supports `after`/`before` paging to a historical window. Verified for `underlying="ETH"` (858 live instruments, real candles).
- OKX bare-`urllib` probes return 403; use a `requests.Session()` with a browser User-Agent (the acquisition module sets this).
- `_run_walkforward` returns `window_returns` + `oos_sharpe`/`oos_max_drawdown`; a fixed tail slice degenerates the aligned options signal (it saturates) — run the **full** tape.
- `_causal_signal_series`/`_toxicities_per_bar` are O(bars × trades) (~110 s/tape sealed). **EVAL-46 wrapper re-implements them with a bisect slice (`_fast_causal_signal`/`_fast_toxicity`) — verified bit-identical, 41.7x faster (~3 s/tape).** Reuse that fast path for EVAL-47 (do not modify the sealed module).
- **DSR quirk:** the sealed `_deflated_sharpe` uses `math.atanh(sr)` which is undefined for |Sharpe|≥1, so `_dsr_of_returns` returns 0.0 for the high-|Sharpe| series typical here (e.g., −10, +1.7).
